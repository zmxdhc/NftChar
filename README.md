# NftChar

Real-time data processing and auto-scaling underpin NftChar, a high-performance engine for scalable smart contract management platforms.

NftChar is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/NftChar.git`
2. `cd NftChar`
3. Install in editable mode: `pip install -e .`

## Configuration

NftChar is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
